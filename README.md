# 工程实践：可重复的数据清洗流水线

## 任务目标
实现命令行清洗程序，处理编码、缺失、重复和非法值；提供小型测试、输入输出样例、失败退出码及 README。导师现场更换样例并追问边界处理。


## 验收维度
验收维度	分值	评价要求
正确性与边界验证	40	语义清楚，核心实现正确，边界测试与结果可核查。
实现与目标库集成	20	接口、代码质量、项目约定与目标任务吻合。
可复现的实验依据	25	环境、版本、命令、数据划分、日志与真实结果完整。
讲解与分析	15	能解释公式到代码、设计选择、结果差异与局限。

## 数据说明
使用自己实际完成的代码和实验材料，可引用题目资料；记录数据来源、许可、划分与版本。

## 需要提交的材料
实现与验证报告：围绕公开 Rubric 说明实现思路、公式与代码对应、运行命令、测试结果和局限，至少 20 字
运行环境：硬件、Python / 框架 / 依赖版本，以及复现命令。
